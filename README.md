\# Computer Vision Mini-Projects



Small real-time computer vision demos built with OpenCV and MediaPipe.



\- \*\*gesture-volume-control\*\* — control system volume with a thumb-index pinch gesture, with a fist-based gesture to lock/unlock the current volume

\- \*\*hand-frame-vision\*\* — frame a rectangle with both hands and apply a thermal/night-vision/edge effect inside it

\- \*\*gaze-tracker\*\* — detect eye contact vs. looking away using iris landmark tracking, logs session summary

\- \*\*steering-wheel-controller\*\* — control a browser racing game using a cardboard steering wheel tracked via colored markers

\- \*\*webcam-darts\*\* — aim and throw virtual darts using hand motion tracking



\## Setup



pip install opencv-python mediapipe==0.10.14 numpy keyboard





Run any script directly, e.g. `python gesture-volume-control/gesture\_volume\_control.py`
